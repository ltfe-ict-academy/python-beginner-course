## Python Exceptions
- [Python Exceptions: An Introduction](https://realpython.com/python-exceptions/#creating-custom-exceptions-in-python)
- [Python's Built-in Exceptions: A Walkthrough With Examples](https://realpython.com/python-built-in-exceptions/)

Python exceptions provide a mechanism for handling errors that occur during the execution of a program. Unlike syntax errors, which are detected by the parser, Python raises exceptions when an error occurs in syntactically correct code.

## Raising Exceptions
- [Python's raise: Effectively Raising Exceptions in Your Code](https://realpython.com/python-raise-exception/)

When you use the raise statement in Python to raise (or throw) an exception, you signal an error or an unusual condition in your program. With raise, you can trigger both built-in and custom exceptions.
