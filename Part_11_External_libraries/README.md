# External libraries

This part of the course covers the use of external libraries in Python. External libraries are collections of pre-written code that can be imported and used in your own programs to extend functionality without having to write everything from scratch.

## Installing External Libraries
To install external libraries, we typically use a package manager called `pip`, which comes bundled with Python. You can install a library using the command line. For example, to install the popular `requests` library for making HTTP requests, you would run:

```
uv pip install requests
```
